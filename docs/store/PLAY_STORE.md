## 2. 스토어 등록정보

**앱 이름(30자):** 지금역 - 지하철 현재역 알림

**간단한 설명(80자):**
```
시작만 누르면 앱을 안 봐도 지금 역·다음 역을 알려 주고, 내릴 역 직전에 진동으로 깨워 줘요
```

**자세한 설명(4000자):**
```
사람이 많아 안내 화면이 안 보일 때, 이어폰 때문에 방송을 못 들었을 때, 폰만 보면 지금 무슨 역인지 알 수 있어요.

■ 시작만 누르면 끝
타는 역을 고르고 시작을 누르세요. 내릴 역은 골라도 되고 안 골라도 돼요.
어느 열차를 탈지 미리 정할 필요가 없어요. 열차가 출발하는 순간 폰의 움직임과 실시간 열차 위치를 맞춰, 실제로 탄 열차를 찾아 따라가요.

■ 실제 운행 그대로
- 열차를 놓쳐도: 놓친 열차는 따라가지 않고, 다음에 탄 열차를 찾아요
- 역 사이에서 멈춰도: "역 사이에서 잠시 정차 중"으로 그대로 보여 줘요
- 갈아타도: 내린 역에서 다음에 탄 열차를 다시 찾아요

■ 앱을 안 봐도
- 잠금화면과 알림창에 이번 역·다음 역이 계속 바뀌어요
- Android 16 이상은 상태 표시줄 왼쪽 위에 이번 역 이름이 떠요
- 내릴 역 직전에 다른 앱 위로 알림이 내려오고 진동이 울려요(무음 모드에서도)

■ 지원 노선
2호선, 수인분당선, 신분당선 (계속 늘려 갈게요)

■ 알아 두세요
- 서울시 실시간 열차 위치 정보를 쓰며, 이 정보는 실제보다 30초~1분 늦을 수 있어요
- GPS(위치 권한)는 쓰지 않아요. 지하에서는 GPS가 잘 안 잡히기 때문에, 폰의 움직임(출발·정차 순간)만 써요
- 회원가입 없이 바로 쓸 수 있어요
```

## 4. 출시
- 프로덕션(또는 먼저 내부 테스트) → 새 버전 만들기 → `app-release.aab` 업로드
  - 파일 위치: `app/build/outputs/bundle/release/app-release.aab`
  - 만드는 법: `./gradlew bundleRelease` (local.properties에 https `API_BASE_URL`과 `RELEASE_*` 서명 값이 있어야 함)
- **Play 앱 서명** 사용(기본값). 우리가 가진 키는 "업로드 키"이고, 실제 배포 서명은 Google이 보관
- 출시 노트: `첫 버전: 2호선·수인분당선·신분당선 현재역·다음역, 내릴 역 알림`
- 국가: 대한민국

## 출시 전에 알고 있어야 할 것
- **실기기로 움직임 감지를 확인하지 못했습니다.** 먼저 "내부 테스트"로 올려 실기기 몇 대로 수인분당선·2호선을 타 보고 프로덕션으로 올리기를 권합니다.
- **서울시 실시간 API는 하루 1,000건**입니다. 한 노선을 15초마다 받으면 약 4시간분이라, 사용자가 늘면 열린데이터광장에 호출 한도 상향을 신청해야 합니다. 한도가 얼마 안 남으면 서버가 간격을 늘리고(최대 1분), 다 쓰면 그날은 "열차 소식을 기다리는 중"으로 보입니다.
- 서버 주소는 고정 IP가 들어간 무료 주소입니다. EC2의 탄력적 IP를 풀면 주소가 바뀌어 **이미 설치된 앱이 서버에 닿지 못합니다.** 탄력적 IP는 계속 유지하세요.
